# Family Todo List - Discord Guide

Welcome! This guide will help you use our family todo list bot in Discord.

## Getting Started

### Joining the Server

1. Click the invite link shared with you
2. Accept the invitation
3. You'll see our family Discord server

### Finding the Bot

Look for **MCP Todo Bot** in the member list (right side). It should have a green dot showing it's online.

## Using the Todo Commands

All commands start with `/todo` followed by what you want to do.

### Adding a Task

**Command**: `/todo add`

**How to use**:
1. Type `/todo add` 
2. Press Tab
3. Type your task (example: "Pack the kitchen boxes")
4. Press Enter

**What you'll see**: "Added #1: Pack the kitchen boxes"

### Viewing All Tasks

**Command**: `/todo list`

**How to use**:
1. Type `/todo list`
2. Press Enter

**What you'll see**: A list of all tasks with their ID numbers and status

### Marking a Task as Done

**Command**: `/todo toggle`

**How to use**:
1. Type `/todo toggle`
2. Press Tab
3. Enter the task number (example: 1)
4. Press Enter

**What you'll see**: "Toggled #1 to done" or "Toggled #1 to not done"

### Adding Notes to a Task

**Command**: `/todo note`

**How to use**:
1. Type `/todo note`
2. Press Tab
3. Enter the task number
4. Press Tab again
5. Type your note (example: "Fragile items on top")
6. Press Enter

**What you'll see**: "Added note to #1: Fragile items on top"

### Removing a Task

**Command**: `/todo remove`

**How to use**:
1. Type `/todo remove`
2. Press Tab
3. Enter the task number
4. Press Enter

**What you'll see**: "Removed #1"

## Tips for Success

### Task IDs
- Each task has a number (ID) like #1, #2, #3
- Use these numbers for toggle, note, and remove commands
- Run `/todo list` to see all IDs

### Best Practices
- Keep task titles short and clear
- Add details using notes instead of long titles
- Check off tasks as you complete them
- Remove tasks that are no longer needed

### Command Help
- Discord will show you hints as you type
- Red text means something is required
- Just follow the prompts!

## Common Situations

**"I don't see the commands"**
- Make sure you're typing `/todo` (with the slash)
- The bot might be offline - check if it has a green dot

**"I forgot the task number"**
- Just run `/todo list` to see all tasks with their numbers

**"I marked the wrong task as done"**
- Use `/todo toggle` with the same number to undo it

**"I want to add more details"**
- Use `/todo note` to add information to any task

## Examples

Here's a typical morning routine:

1. `/todo add Call moving company` → "Added #1: Call moving company"
2. `/todo add Pack bedroom closet` → "Added #2: Pack bedroom closet"
